# GoFT8 Agent Roster

These role files define the six-person improvement team used for this repository.
Use them as prompts/checklists when delegating or reviewing work from
`IMPROVEMENT_PLAN.md`.

- `project-manager.md`: backlog, milestone, and PR gate owner.
- `developer-core.md`: Go implementation owner for API, WAV, encoder, decoder.
- `developer-tooling.md`: CI, tests, CLI, docs, and developer workflow owner.
- `security-consultant.md`: malformed input, fuzzing, and dependency risk owner.
- `performance-tester.md`: benchmark and regression owner.
- `functional-tester.md`: end-to-end user workflow owner.
