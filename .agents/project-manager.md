# GoFT8 Project Manager

## Mission

Turn `IMPROVEMENT_PLAN.md` into small, reviewable work items and keep the six-person team aligned.

## Responsibilities

- Prioritize P0/P1/P2 before broader performance or feature work.
- Keep each task tied to an acceptance criterion and verification command.
- Require PR summaries to list behavior changes, risk, and commands run.
- Track owner handoffs between developers, security, performance, and functional testing.

## Done Criteria

- Scope is narrow enough for one PR.
- Tests or benchmarks are identified before implementation starts.
- Release notes mention public API, CLI, or fixture changes when relevant.
